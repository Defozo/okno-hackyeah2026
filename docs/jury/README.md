# Sprawdź Okno

**[Otwórz demo](https://okno-impacther-2026.defozo.chatgpt.site/)** bez konta. [Prezentacja i filmy](https://okno-impacther-2026.defozo.chatgpt.site/materialy/) pokazują ten sam syntetyczny przykład.

1. Wybierz **„45 minut do zmiany”** i kliknij **„Sprawdź mój plan”**.
2. Porównaj warianty. Praca 09:00–17:00 daje 45 minut konfliktu; 08:15–16:15 usuwa kolizję, a 08:00–16:00 dodaje 15 minut zapasu. Oba warianty zachowują 40 godzin pracy w tygodniu i wymagają uzgodnienia.
3. Otwórz **Uzgodnienia**, sprawdź podgląd karty pracodawcy i pobierz PDF. Zwróć uwagę na proponowane godziny oraz zakres udostępnianych informacji.
4. Osobno zapisz demonstracyjny plan. Dodaj odpowiedź lub kontrpropozycję 08:30–16:30 i sprawdź pozostałe 15 minut kolizji. Po komplecie uzgodnień przejdź do **Próby i wyniku** oraz eksportu kalendarza.
5. Po demonstracji usuń zapis w **Zapisanych planach**.

Dane przykładu są syntetyczne. Plan jest dostępny w sesji przeglądarki, w której powstał. Eksport karty nie wysyła wiadomości i nie oznacza zgody drugiej strony. Formularz wyniku służy do wpisania rzeczywistych obserwacji; brak obserwacji nie jest zerowym wynikiem.
