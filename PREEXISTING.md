# Pochodzenie projektu

Przed implementacją Okna dostępne były materiały zadania ImpactHER, ich ekstrakcje tekstowe, propozycje rozwiązania i plan produktu z 3 października 2026. Nie zawierały aplikacji, solvera ani konfiguracji uruchomienia Okna.

Implementacja katalogów `api`, `web`, `data`, `infra`, `tests` i `scripts` rozpoczęła się 3 października 2026. Wykorzystano narzędzia ogólnego przeznaczenia, Docker, Python, Node, psst i biblioteki wymienione w [THIRD_PARTY.md](THIRD_PARTY.md). Narzędzia, konta usług i klucze API były zasobami wcześniejszymi; nie są dystrybuowane z projektem.
